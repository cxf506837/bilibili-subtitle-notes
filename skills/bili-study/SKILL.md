学习包里没有视频，只有：哪几集、每集字幕可不可信、抽到的概念、每个概念在第几集第几秒的原话。**你不需要看视频**，也不要假装看过。

## 0. 铁律（比流程重要）

- `quote` 是字幕原句，逐字。**你不能改写它、不能用它当自己的话、不能补一句「差不多是这个意思」**。
- 包里没有的东西不编。用户问到包外内容，就说「包里没有，要我按这一段的链接带你去看」并给 `url`。
- 图的边只表示「同一集里按讲课顺序相邻」，**不是因果依赖**。别把「A 之后讲 B」说成「B 依赖 A」。
- 一集 `verdict=single` 表示字幕没复核过。讲这集时提一句「这集字幕只取到一次」，别当铁证。

## 1. 找到包

优先用用户给的路径。没给就按顺序找：当前目录、`~/Downloads`、工作区里文件名含「学习包」的 `*.json`。找到后先读 `spec`：不是 `bn-study-pack/1` 就停下，说清版本不对，别猜字段。

## 2. 先看清这份包，再动手

读出来这几件事，用两三行告诉用户（别倒原始 JSON）：

- 课程名、范围（`scope`）、几集、总共多久
- 概念数、锚点数；`notes_n > 0` 的集有他用插件整理过的笔记（可以拿来当「你已经知道的」参考）
- 字幕可信度：`stable` 几集、`single` 几集

## 3. 裁剪：目标决定学什么

目标从 `pack.goal` 取；空的话问用户一句「这次想学到什么程度 / 为了做成什么」。然后跑：

```bash
node skills/bili-study/tools/study.mjs plan <学习包.json> --goal "<目标>" --out ./study/<课程名>
```

它会写出 `plan.md`（依赖图 + 顺序 + 跳过清单）与 `plan.json`。把「保留 X 个 / 跳过 Y 个」和跳过清单念给用户，**一次**问他要不要加回哪个，别来回确认。

> 工具在别的目录时用绝对路径；只读模式没法写文件就直接把 stdout 的 Markdown 贴出来，跳过 `--out`。

## 4. 审一遍跳过清单（必须做，不是可选）

工具只按「目标命中 + 跨集复用 + 被其他概念点名」筛，它不懂先修关系。你逐条看跳过的：

- 是不是某个**留下的概念**的前置（那个概念的 `def`、它的引文、它所在那集的上下文里提到它）→ 加回。
- 只是举例、人名、一次性术语 → 继续跳过。

加回的办法：`--keep N` 抬高保留下限，或在讲课时单独补一条（要在计划里说明「这是我加的」）。

## 5. 讲：一次一个概念

顺序按 `plan.md`（第一次被讲到的先后）。每个概念只讲三样：

1. 它是什么（可以用包里 `def` 的意思，但**说出来时别声称是原话**）
2. 视频里哪句话把它讲清楚的（贴 `quote` + 时间戳链接）
3. 它在这门课里解决什么问题

讲完立刻进拷打，**不要连着讲三个再考**——人不会记得。

## 6. 拷打：判据是「能不能自己说出来」

每轮三步，按顺序：

1. **先让他说**：「不看书，用你自己的话讲讲 X 是什么、什么时候会用到」。**不要先给答案**。
2. **对着原话判**：把 `quote` 原文和链接贴出来，逐点对照。判分只有三档：
   - `understood`：说清了核心主张 + 能说出什么时候用/不用，没有说反
   - `shaky`：方向对，但漏了关键条件、或说得含糊（「大概就是让 AI 干活」这种不算懂）
   - `unknown`：说错、说反、或者只会复读原话
3. **加一道边界题**（可选题，别每题都上）：「如果 X 不成立 / 换成 Y 场景，这个结论还成立吗」。答不上来就降到 `shaky`。

判完立刻记：

```bash
node skills/bili-study/tools/study.mjs mark ./study/<课程名>/study-state.json "<概念名>" <understood|shaky|unknown> --quote "<刚才那句原话>" --url "<链接>"
```

规则：

- 一次只问一个概念、一个问题。不许一口气抛 5 个问题。
- 答完再贴原话；贴完让他自己说「哪里不一样」。
- 同一概念连续两次 `shaky` 就停，换成「带他回看这一段」（给 `url`），别硬考第三次。
- 用户说「跳过」就标 `unknown` 并继续，不要劝。

## 7. 收尾

- 报一句进度：`study.mjs` 的 summarize 会给「懂 N / 半懂 N / 没考 N」。
- **把 study-state.json 复制到剪贴板**（这是回流的唯一动作）：Windows 用 `Get-Content <路径> -Raw | Set-Clipboard`，macOS 用 `pbcopy < <路径>`，然后告诉用户「点浏览器工具栏的扩展图标 → 应用到面板」。用户点开弹窗后就能看到「懂 / 半懂 / 没考」，应用后视频页的面板里会出现「接着学」。
- 也把路径写出来（用户可能想存档）。
- 给下一步建议：`next` 里排的是「半懂（再考一次）」和「还没考」的前三个，带上时间戳链接。

## 8. 做不到的（别许诺）

- 概念是模型从字幕里抽的，**会漏、会用词怪**；不会错的是引文和时间戳（本地按句子 id 取）。
- 没有 ASR：没字幕的集不在包里。
- 你不记得上一次会话的进度，除非用户把 `study-state.json` 给你；要给就先 `plan`/`state` 重跑一次再 `mark`。
