## Q1｜agent 说「改好了」，你信什么？

你让 agent 改完一处代码，它说「已完成，刷新一下就好了」。你判断它**真的**完成的依据是：

- A. 它自己说完成，并解释了改了什么
- B. 你刷新页面点了一遍，看起来正常
- C. 有一组能自动跑的命令，跑完全绿；界面改动另有截图
- D. 你看了 diff，逻辑没问题
- E. 不确定

**对应时段**：01:32–03:48（测试的本质 / 不给测试就像蒙眼投篮）
**答案**：C。B 是「人肉测试员」，D 是必要但不充分（看不见界面），A 是视频开头的翻车现场。

## Q2｜agent 写了 20 个测试，全绿。你先怀疑什么？

- A. 覆盖不够，应该再多写点
- B. 测试是「自己考自己」：标准答案直接取自代码自己的输出，代码错了它也绿
- C. 测试跑得太慢
- D. 环境或依赖版本问题
- E. 不确定

**对应时段**：03:48–04:55（三种垃圾测试：假装测试 / 废话测试 / 只抠细节）
**答案**：B。A 是最常见但错得最远的反应——数量不解决问题，**自证式测试**才是「全绿但没用」的头号来源。

## Q3｜接口测试全绿，用户说「按钮点不了」

最可能漏掉的是哪一层？

- A. 单元测试覆盖率不够
- B. 没有人像真人一样打开浏览器点一遍、并留下截图
- C. 没做 code review
- D. 后端没加索引

**对应时段**：04:55–06:50（测试看不见界面 / Playwright）
**答案**：B。视频原话的要点：样式歪了、按钮被图片挡住，**代码里的测试根本看不见**。
