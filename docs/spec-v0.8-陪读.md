# v0.8 规格：B站 陪读（不是笔记）

> 2026-11-14 grill 后第一版规格。**未实现**，待用户拍板。
> 决策依据见 docs/decisions-video-learning-agent.md（D1–D7）。

## 要解决的问题（一句话）

「我不知道这条视频值不值得学、该学哪一部分」——用户没有能力自己提出正确的问题，所以**不能让用户先开口**。

## 我上一版方案的洞（用户当场指出）

「我都不知道要学哪个部分，甚至是要不要学这个视频，那么我该问什么，插件又该问什么，我怕反倒是越问越差。」
—— 正确。若让模型凭空生成「3 个问题」，它会问出视频自己的话题（「本视频介绍了 Playwright 的三种用法」），既不出题也不给判断，多轮之后只会更乱。

## 修正：不问用户，先测用户

工具不需要知道用户的人生目标，只需要两样最小输入：

1. **一句话的你**（开屏一次性，存本地，可改）
   例：「agent 应用开发，现在卡在没法验证对不对、要交付给别人用」。
   作用：给「值不值得学」提供判据。没有它，任何「该不该学」都是废话。
2. **3 道前测题的答题结果**（可只点「会 / 不会 / 不确定」，不打字，约 1–2 分钟）
   作用：定位用户在这条视频主题上的真实位置。前测比后测更能暴露盲区。

有了这两样，「该学哪部分」才可计算：

| 答题结果 | 判断 | 输出 |
|---|---|---|
| 会 | 已懂 | 该段跳过 |
| 不会 | 盲区 | 该段精看，标为必看 |
| 不确定 | 自以为懂 | 该段精看 + 标记「重点核对」 |

## 流程

1. 抓字幕（复用现有能力：blocks + 时间戳 + 错位判定）。
2. 把全片合并成 **5–9 个主题段**（不是逐句摘要）。
3. 每段提炼「看完这段你能**做**的一件事」（能力点），不是「讲了什么」。
4. 生成 **3 道前测题**，覆盖不同段，题型为可判分的判断/选择，允许「不确定」。
5. 一屏结论（≤3 行）：
   - 这条值不值得精看（一句话 + 一句理由，理由必须引用「一句话的你」）
   - 哪几段跳、哪几段必看（带时间点）
6. 追问框：自动挂当前段上下文，回答 ≤150 字，**每条回答必须带一个「跳到 12:34 看原话」**。
7. **不产出文档**。可选导出只有「3 行结论 + 时间点」，默认关闭。

## 防「越问越差」的三条硬规矩

1. 每轮回答必须落到一个决策：**看这一段 / 跳过这一段 / 回头再看一遍**。落不到就不许回答。
2. 最多 5 轮；到 5 轮必须给结论并停，不许继续发散。
3. 不许扩写知识（「顺便讲讲 X 也很重要」一律禁止）。**只解释这条视频里的东西**。

## 发布方式（用户定：GitHub 开源，自行部署）

- 不投 Edge 商店。代价：没有商店分发；收益：无审核、无维护窗口。
- 必须有：README 三步安装、API key 存处说明（chrome.storage.local，不上传）、LICENSE、隐私一句话。
- 「别人一次装成功」是验收项之一，不是文档补充。

## 最大风险

**前测题会退化成考背诵**（「视频里说 Playwright 需要几步？」）。这是本方案唯一的死穴。
判据：答对前测 ≠ 能复述视频原话。若题目只能靠记忆视频原文答对，即判失败，必须重出题。

## 两周硬判据（来自 grill）

用它看完 **S2-4 / S2-5 / S2-8** 三条视频（用户本来就要学的）。两周内打开 <5 次 ⇒ 项目停止。

## 修订 R1（2026-11-14，打样后）：「答题」作废，改成「做任务」；选片前移

### 触发
用户对三道前测题的回答：「我只会当用户真的用一遍，我从来不信什么改好了和什么破测试，只有真的能用才算好……这是三道题的，也是对整测试部分的唯一答案。」
以及：「选择题肯定不行，难道是用户先搜索，ai推荐，然后ai总结这是啥，并询问你要不要学这个？」

### 结论 1：产物从「题」改成「任务」
判据是「真的能用」，那就不能用选择题去近似它——选择题测的是「你同不同意」，不是「你会不会做」。
改为：每条视频给一个 **5–10 分钟能真跑一遍的迷你任务**（在你自己的项目里做，不是沙盒练习）。

- 跑通 ⇒ 这一段你已经会了，跳过
- 卡住 ⇒ 这一段必看，而且你看的时候是有目的的（解决卡住的那一步）

这同时满足「不喜欢读字」：任务要动手，不要阅读。

### 结论 2：流程前移成三级
1. **选（新增，最重要）**：候选池（搜索结果 / UP 合集 / 系列目录）→ 每条一句话「这条能让你会做 X」+ 与你「项目卡点」对照 → 值得 / 不值得 + 一句理由。
2. **判**：决定学之后，给那个迷你任务。
3. **补**：任务卡住，才跳到具体时段看原话；追问只解释这一小段。

原 v0.8 的「3 道前测题 + 一屏结论」降级为第 2、3 级的一种素材，不再是入口。

### 结论 3：选择题整体否决
不再用 ABCD。要判断「懂没懂」，只有两种合法输入：**任务跑通 / 没跑通**；以及用户自己说的一句话。
