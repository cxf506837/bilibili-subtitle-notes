## 为什么不缺一个「AI 总结视频」

B站 字幕接口**同一个视频多刷几次会返回不同文件**：作者自己的 401 秒课程连取 8 次，拿到 4 种不同内容（正确那份只出现 5 次，其余是电动车、超长字幕、HTML 错误页）。所以字幕进模型之前先过闸门——最多取样 5 次、按哈希投票，票数不够就判「不确定」让你重试，绝不拿一份可能属于别的视频的字幕去写笔记。

- 每条结论都能点回**原字幕句**，不是模型复述
- 拿不准就说拿不准：「两次取样一致」只说明取样稳定，不说明内容是这个视频的，所以界面不写"已验证"
- 你填的 API Key 只在本机，直连你自己填的端点，没有中间服务器

实测数据（60 条视频可用率、8 次取样 4 种文件、786 条离线测试）见 [docs/evidence.md](docs/evidence.md)；隐私说明见 [PRIVACY.md](PRIVACY.md)。

## 装（约 3 分钟）

1. 先**登录 B站**（未登录时字幕接口返回 0 轨）。
2. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`），打开右上角「开发人员模式」。
3. 点「加载解压缩的扩展」，选本仓库根目录（有 `manifest.json` 的那一层）。
4. 点工具栏拼图图标把「B站字幕笔记」钉出来；打开任意视频页点它，按「设置」选一家服务商（预设会自动填好 API Base 和模型），再填 Key。
   不想申请 Key 也行：字幕抓稳后直接点「导出」，得到逐句字幕全文（第 4 步之外的部分照常用）。

设置页内置 6 家预设：DeepSeek / OpenAI / 通义千问 / 智谱 GLM / Moonshot / 本机 Ollama。填**别的**域名会在保存时被挡——浏览器扩展只能连 `manifest.json` 里声明过的域名，没声明的域名在 MV3 里只会报一句 `TypeError: Failed to fetch`，分不清是断网、Key 错还是没权限，所以干脆在保存那一步就说清楚。想加服务商请开 issue。不想自己打包的话，[Releases](https://github.com/cxf506837/bilibili-subtitle-notes/releases) 里有打好的 zip（完整版带本地 OCR，轻量版 114 KB）。装不上、图标灰着、Key 存不住 → [docs/install.md](docs/install.md)。

## 用

- 键盘也能用：Tab 到一条笔记，回车展开/收起；Tab 到时间戳，回车跳到那一秒。


- 笔记默认只显示一行摘要（有逐字引文也不铺开），点摘要才展开引文和解读；从大纲点一条会顺手把它展开
- 面板跟着播放头走：跨过一段末尾才写这一段，没看过的地方不写、不剧透
- 跳过的区间画成虚线占位条：要么「总结这段」（花钱），要么「去看这段」
- 字幕只取到过一份（面板写「单次取样（未复核）」）时，工具栏会多一个「再取样」：再取一次，两次一致才算核过（B站 字幕接口会抖，也会张冠李戴）
- 用的是上次存下的字幕时，那个按钮变成「重新核对」：点一下重新取一份对照，取不到就继续用上次那份（缓存不会自己变，错了得你说了算）
- 「导出」出 Markdown：frontmatter 带 `bvid` / `tags`（bilibili、视频笔记），有笔记时先给一段 `## 大纲`，正文每句都能点回原句，直接进 Obsidian
- 合集 / 多 P：面板多一个「导出全部 P」，把所有分 P 的字幕导进同一个 Markdown（中途可以停）；哪一 P 没导出来、为什么，写在文件末尾
- **只导你要的那一段**：课程清单里每集前面有勾选框，按 S1 / S2 分组、每组可「全选」；勾几集就只导这几集，文件名叫「（S2 · 9 集）」，frontmatter 里 `scope: S2`。第一次没导出来的集会在结尾自动再取一轮（字幕接口会抖），还不行才写进「未导出的集」并给原因
- **学习页**：面板 ⋯ 菜单里点「学习页」，一屏三栏——左边这门课看过几集、每集几条笔记，中间按集列出所有概念（跨集的概念标「跨 N 集」）；每条概念下面一行「出现在 N 集 · M 处」，点开就是它在这门课的每一次出现——哪一集、第几秒、当时怎么说的，时间戳点一下**就在这一页看**（内嵌 B站 播放器，带 `t=`，看完点「收起」回到列表；想开原页面就点「在 B站 打开」），右边是掌握度和用法，还有一张「今天先看这几个」——按 `半懂 → 没考过 → 已懂` 排序、跨集概念加权挑 6 个，点一行就在这一页播到那一秒（考完再导一次状态，这张卡跟着变）。中栏顶部还有「按集 / 按概念」两个按钮：`按概念` 把一个概念的每处原话合成一张卡（跨的集越多越靠前，比如「agent」就是一张卡 · 跨 5 集 · 12 处），不用在各集之间来回找同一个词。按概念时右上角还有一枚「还没弄懂 N」——只留半懂和没考过的概念（没导入过掌握度就不出现），可以和「没看过 / 跨集」、搜索一起叠加，用来决定「这一门课里我现在该回看哪些」。这个顺序和右栏「今天先看这几个」是同一套，右栏底下还有个「看全部 N 个 →」，点它直接跳到这里。搜概念名、定义里的词、原话里的句子都算；空格分隔多个词是「都要命中」。左栏上方的「全部 / 没看过 / 跨集」切换中栏视角：`没看过` 只留还没看完的集（接着学少滚一点），`跨集` 只留出现在两集以上的概念（它们才是知识点之间的连接），屏幕上会写清现在看的是哪个视角、还剩多少。不用打开视频，纯本地读 `chrome.storage.local`，不联网不花钱。面板课程条上还有一枚「跨集 N」徽标，点它直接开学习页并停在跨集视角。
- **交给 agent**：课程清单里勾几集，点「交给 agent（N 集）」，下载一份学习包（`.json` + `.md`）：每集字幕可不可信、抽到的概念、每个概念在第几集第几秒被讲到的**逐字原话**。agent 拿它就能按你的目标裁剪、画依赖图、出题考你，不用自己看视频。格式说明见 [docs/agent-integration.md](docs/agent-integration.md) 下载完它会顺手把「读哪个文件、找不到就问我路径」这句话放进剪贴板；没放进去就点扩展图标，最上面有「学习包已导出 · 复制给 agent 的话」。走这条路之前先看清按钮：工具栏的「导出」只导出当前这一集，整门课要在课程清单底部点「交给 agent（N 集）」——如果你先点了「导出」，状态条会提醒你一次（同一集只提醒一次）。导出成功后，面板顶部会留一张卡片：文件名、「复制「交给 agent」的话」、以及「存 Markdown」（`.md` 不自动下，因为第二份自动下载会被浏览器静默拦掉）。
- **直接送到本机 agent**：不想走「下载目录 → 手动打开」也行。仓库里 [tools/agent-bridge](tools/agent-bridge/README.md) 含一个只监听 `127.0.0.1` 的收件端，`node bn-agent-hook.mjs` 起一次，然后在设置页打开「本地 agent」并填 `http://127.0.0.1:8791/bn-pack`。之后点「交给 agent（N 集）」，学习包会同时落进下载目录和收件端的 inbox，卡片上会写「已经送到本地 agent」或「连不上」（连不上不影响导出）。它只把文件交给**你自己起的**那个端点，不往 agent 窗口里打字、不模拟回车。
- **省掉「先找文件、再说要学什么」**：学习包文件名固定以 `bn-study-` 开头，剪贴板里那句也会教 agent「在下载目录找最新的 `bn-study-*.json`」——之后一句「学最新的学习包」就够。想连切窗口都省掉，用仓库里的 [tools/agent-bridge](tools/agent-bridge/README.md)：新包一落盘就把 agent 窗口拉到前面，你只要 `Ctrl+V` → `Enter`（它不点击、不发消息）
- **学完把掌握度带回面板**：agent 拷打完把 `study-state.json` 复制到剪贴板，点扩展图标 → 「应用到面板」；回到视频页，课程条下面就是「掌握度 懂 5 · 半懂 11 · 没考 75」，点开能看到「接着学」该跳哪一秒，和已经能讲清的概念。只读你复制的那一份，不联网
- **配一个 agent 学完它**：仓库里带 `skills/bili-study`（复制到 agent 的 skills 目录即可；不想 clone 仓库的，去 [Releases](https://github.com/cxf506837/bilibili-subtitle-notes/releases) 下 `bili-study-skill-v1.zip`，解开就是 `bili-study/`）。它会按你的目标裁掉不需要的概念、出依赖图、用**逐字原话**一道一道考你，答完把「懂 / 半懂 / 没考」写进 `study-state.json`。流程见 [skills/bili-study/SKILL.md](skills/bili-study/SKILL.md)
- **合集 / 多 P 顶部有课程条**：课程名 + 「24 集 · 2 小时 57 分 · 已看 1 集」，点开是每集清单（✓ 是看过的，当前集高亮），点一集直接跳过去；「继续」跳到下一集没看过的。进度记在本机，关掉浏览器再回来还在
- **概念视图**：工具栏「概念」把一集集抽出来的概念卡拼成「这门课到底讲了哪些概念」——按集分组，每个概念写着它是什么、在哪几集第几秒被讲到、点原话直接跳过去；同一概念跨集出现会标「跨 2 集」并排到最前（这些才是知识点之间的连接）；回流过掌握度后直接标「懂 / 半懂」。只在这一集出现、标题里也没有的词会被标灰（可能是闲聊），不删
- **没填 API Key 也能用**：抓完字幕直接点「导出」，拿到的是逐句字幕全文（每句一个时间戳、可点回原句），只是没有 AI 整理的结论
- 关掉页面再打开，笔记从 IndexedDB 原样恢复，不重跑闸门、不重复花钱
- 失败会说清是哪一种：没有字幕 / 字幕只有一部分 / 字幕和视频对不上 / 没登录 / 清晰度太低 …
- **点扩展图标**：顶上第一行就是「当前视频 · 已经攒了 N 条笔记 → 打开面板」—— 面板收起来了、或者刚装好不知道从哪开始，点它就回去；下面才是「搜你攒下的所有笔记」，输入关键词（空格分隔多个词，多个词同时命中才算）或人名，结果显示在哪个视频的哪一秒，点一下直接跳回那一句的原时间点。第三块是「接着学」：最近看过的课、看到第几集、掌握度（懂/半懂/没考），点一行回到上次那一集那一秒，不在视频页也能点
- 「诊断」按钮一直在（不是只有出错才出现）：一键拿到版本 / 页面 / 字幕判定 / 端点（不含 Key），贴进 issue 就能复现；状态条不是绿色时会高亮

## 不做

- 只做 B站 桌面网页 `bilibili.com/video/`（含多 P 分集）。直播回放、番剧、课程不做
- 不上传视频、不建账号、没有服务器、不做云同步
- 「画面文字」「画面字幕兜底」在本机跑 OCR（约 29 MB，打包进完整版），识别一定有错字，别当原话

## 费用

70 分钟视频约 120 段，实测约 1010 token/段，合计约 12 万 token ≈ ¥0.2（DeepSeek 现价：输入 ¥2/M、缓存命中 ¥0.2/M、输出 ¥3/M）。面板右上角按这个真价算实时花费，鼠标悬停能看输入/命中/输出三段。不会自己偷偷花：默认只有你点「总结这段 / 整理全片」才调模型，另有单视频与每日 token 上限（设置里可调，0 = 不限）。
