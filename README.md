# B站可核对笔记（v0.7.3）

跟播放头边看边写，每条结论都能点回原句。

浏览器扩展（Chromium Edge / Chrome，MV3）。只做 B站桌面网页 `bilibili.com/video/` 视频（含多 P 分集），直播回放与番剧不做。

---

## 一、装之前

1. **先登录 B站**。字幕接口在未登录时返回 0 轨（`need_login_subtitle: true`），这是硬前提，不是可选优化。
2. **准备一个 OpenAI 兼容的 API**（DeepSeek / 通义 / 智谱 / Moonshot / OpenAI 都能填）。填三项：API Base（到 `/v1` 为止）、模型名、API Key。
   Key 只存在浏览器本地 `chrome.storage.local`，只发给你自己填的那个 API Base，不经任何中间服务器。
3. **用 DeepSeek 的话**：API Base 填 `https://api.deepseek.com/v1`，模型填 `deepseek-flash`（或 `deepseek-v4-pro`）。
   DeepSeek 默认开推理，会把 max_tokens 全烧在 reasoning 上、正文变成空串；扩展检测到 endpoint 里有 `deepseek` 就自动带 `thinking: {type:"disabled"}`，你不用管。

4. **画面文字（PPT / 板书）要 720p 以上**。截的是视频解码像素，不是屏幕截图，所以面板、弹幕不会被截进去；但 360p 的中文正文只有 8~10 像素高，OCR 认不出来。未登录 B站 最高 480p，登录后才能 1080p。
   这一层完全在你本机跑（ONNX Runtime + PP-OCRv6 tiny，约 29MB 的模型和 wasm 随扩展一起装），不联网、不花钱。

## 二、安装

装到**你自己的**浏览器配置里（推荐，这样它和你其他扩展排在一起，重启也不会消失）：

1. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）。
2. 打开右上角「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本仓库根目录 `bili-notes/`（有 `manifest.json` 的那一层）。
4. 地址栏右边点拼图图标（`⋮⋮`），把「**B站可核对笔记**」钉到工具栏——v0.7.3 起它有了自己的图标（蓝色方块＋三行白线），点一下就能打开面板。
5. 打开任意 B站视频页，点工具栏图标（或等浮层自己出来），点浮层里的「设置」填 API。

升级：下拉新版本覆盖目录，然后在该扩展卡片上点「重新加载」。

**装不进去时按这个排查（v0.7.3 实测）**：

- 命令行走不通了：`msedge --load-extension=...` 从 Edge 136 起会把扩展记成「不支持的命令行扩展」并禁用它（disable_reasons 里是 1<<24），**别再试**。只能走上面第 3 步的「加载解压缩的扩展」。
- 选了目录却没反应：同一个路径如果以前加载过、又被 Edge 记成损坏条目，再用这个路径加载会静默失败。把目录**复制成新名字**（比如 bili-notes-my）再选就行——解压缩扩展的 id 是由路径算出来的，换路径就是换 id。
- 换路径/id 之后 API Key 会「丢」（读的是按 id 存的 storage）：先去旧 id 的 Local Extension Settings/<旧id> 把整个目录拷到 Local Extension Settings/<新id>，再点「重新加载」，就不用重填。重填也只要 30 秒。
- 图标钉不上工具栏：先把窗口最大化再点拼图图标；实在不行关掉浏览器，把扩展 id 写进 Edge/User Data/Default/Preferences 的 extensions.pinned_extensions 数组（先备份该文件），重启就有。
- 装好后浏览器仍可能长期挂一条黄条「此扩展不是来自任何已知来源」，属正常，别点「删除」。

**两个包（v0.7.3）**：

| 包 | 大小 | 说明 |
| --- | --- | --- |
| `dist/bili-notes-v0.7.3.zip` | 11,602,309 字节（约 11.6 MB，23 个文件） | 完整包，带本地 OCR 运行时（`vendor/ocr`，约 29 MB 解压后），「画面文字」「画面字幕」两个功能可用 |
| `dist/bili-notes-v0.7.3-lite.zip` | **74,003 字节（约 72 KB，17 个文件）** | 轻量包，不含本地 OCR。只做「跟着字幕写笔记」，界面上**不会出现**「画面文字」「用画面字幕试试」这些按钮（扩展启动时会探一次 OCR 文件在不在，不在就不显示，不会给你一个点了就报错的按钮） |

自己打包：`node test/zip.mjs`（完整）/ `node test/zip.mjs --lite`（轻量）。

> **关于「专用 profile」**：开发联调时我用的是独立配置档（`dist/edge-profile`，由 `start-edge.ps1` 启动）。独立配置档里看不到你原来的扩展和书签，这是隔离的代价，不是 bug。想放一起就按上面四步装进你自己的配置，然后把 `start-edge.ps1` 那套丢掉即可（注意：两边配置不共享，API Key 要重填一次）。

## 三、怎么用

- **点工具栏图标就能用（v0.7.3）**：在视频页点一下图标 → 面板被唤出（收起态会自己展开，并闪一下左边框确认是它开了）；如果这个页面是在装扩展之前打开的，图标会当场把面板脚本补注入进来，不用按 F5 重来。
  不在视频页（首页、动态、别人的收藏夹）点图标 → 直接给你开一个 B站 首页标签，而不是点了没反应。
- 浮层跟着播放头走：播放头跨过某一段末尾，才给这一段写笔记；没看过的地方不写、不剧透。
- **跳过的段落画成虚线占位条**：写「未观看 6:48–57:02 · 88 段」，两个按钮——
  - 「总结这段」：照样调模型把这段补出来（会花钱，按钮悬停能看到大概要多少 token）；
  - 「去看这段」：把播放头跳到这段开头，让你自己看。
  正在看的那一段如果笔记还没出来，占位条写的是「正在看 …」。
- **小节标题（v0.7.0）**：每攒够 8 段笔记，扩展会拿这 8 段各自的「一句话」去起一个小节标题，显示在大纲顶部——
  「0:00–5:40 · AI 改代码的 git 快照与提示词」，下面才是这一节里各段的一句话。点小节标题直接跳到这一节开头。
  只喂这 8 段的一句话、**不喂全片摘要**：喂全片会让模型拿后面的结论倒推，写出「后见之明」式的小节名。标题超过 18 字会截断，带「本节讲」「第一部分」这种空话前缀会被剥掉。
- **一个段落只要看过 80% 就算看过**（哪怕你是从中间拖进来的），不会因为「没从段首开始」就永远不总结。
- 每条笔记有原话（逐字引用 + 可点的时间）+ 人话解释。点时间跳过去。
  人话解释的要求写在提示词里（v0.7.0 又收紧了一遍）：**先用「它在解决什么问题」开头，别用「它是什么」**；能用动词就别把动作变成名词；单句不超过 25 字；
  并且给了一条反例一条正例——反例是「讲师深入阐述了协方差矩阵的统计学意义，揭示了变量间的协同变化规律」（拔高、堆名词、等于没说），正例是「它只回答一个问题：两个东西是不是一起动」。
  遇到模型不认识的专名（比如字幕里的 matlab），它必须写「提到了 X，但不确定指什么」，**不许编一个听起来合理的定义**。
- **收起面板后不会找不到（v0.7.1）**：收起后右边贴一条 **52px 宽的蓝色竖条**——上面一个蓝色圆角「展开 ▸」、中间竖排「笔记」、最下面一个数字徽标显示已生成的笔记条数。整条都能点开（之前是一根 44px 的淡灰文字，深色页面上几乎看不见）。
- **滚动不抢**：新笔记自动跟在底部；你手动往上滚就锁定，不再自动跳，右下角出现「回到最新 ↓」，点它回到最新。
- **失败了会说清是什么事（v0.7.2）**：每种失败都有自己的标题和「你能做什么」，不再共用一句「出错了」——
  「这个视频没有字幕」「字幕只有一部分」「字幕比视频还长」「B站 返回了空字幕」「字幕和视频对不上」「B站 几次给的字幕都不一样」「没登录 B站」「清晰度太低，认不出画面字幕」。
  标题下面两行：发生了什么（是不是 B站 那边的问题、和你操作无关）＋ 现在该点哪个按钮。
- **冷启动恢复**：关掉页面再打开同一个视频，笔记从 IndexedDB 里原样恢复（状态条写「已恢复」），不重跑闸门、不重复花钱；没看过的区间仍然是虚线占位条。
- **走神补课**：你切走标签页超过 90 秒、或暂停超过 2 分钟，回来时面板顶部出一条横幅——
  「你离开了 3:00 · 这段记了 2 段 [展开补课] [忽略]」。点「展开补课」进入补课视图：只给这段的一句话级要点（每条带「去看这段」），没记的部分给「总结这段」。8 秒后横幅缩成小挂件「补课 · 1:40」，点它随时能打开。
  这条提示同一次播放只自动弹一次，关掉后同一视频 24 小时内不再弹，只留小挂件；在「设置」里可以整个关掉。它只记时间戳和原因，不记你去了哪里。
- **画面文字（v0.4.0）**：讲 PPT、板书、代码的课，视频画面本身承载主线。扩展会自己截帧——只在画面**连续稳住约 2.4 秒**时截一张（画面一直在动的游戏/影视基本不会被截），同一张画面不重复识别，识别出来的文字挂在时间最近的笔记上，标题写成「画面文字 · 11:01 / 11:26」，点开能看到 OCR 原文。
  这块文字只作为模型理解上下文的**旁证**：它可以进「人话解释」，但**永远不会被当成原话引用**（引文只从字幕原文里来，这就是可核对的底线）。设置里可以关掉。
- **画面字幕兜底（v0.6.0）**：有的视频字幕是**直接烧在画面里**的（搬运的公开课、纪录片、外语剪辑最常见），B站 接口返回 0 条字幕轨——这时失败面板会多一个「用画面字幕试试」。
  点了之后扩展每 0.6 秒截一次画面底部那条字幕带、在本机用 OCR 读字，再把一句句字幕按时间拼成「带时间的句子」，走和正常字幕一样的切块/总结流程。笔记会标「· 画面字幕（识别）」，状态条写「画面字幕 · 本地识别」。
  几条硬约束：**必须先把清晰度切到 720P 以上**（480p 的中文字只有十几像素高，会直接拒绝，提示「清晰度太低」）；**要保持播放**（它跟着播放头采样，暂停就不认）；只认画面下方那条字幕带，中英双语字幕只取中文行，右下角台标/水印文字会被挖掉。
  它是「读画面」而不是「读字幕文件」，所以识别一定有错字（数字、人名、公式最容易错）——这些字会进原话，看到可疑的地方以原视频为准。设置里可以关掉。
- **音画对齐（v0.5.0，默认关）**：字幕的时间轴可能整体早/晚，或者越到后面越偏（重剪过的视频常见）。打开后扩展会接管一次音频输出、只算音量不录音，用它和字幕的停顿位置对齐；判出偏移就把界面上的时间和跳转按音频时间校正，状态条下方多一行小字说明（「字幕比音频早 2.3s（时间已按音频校正）」），没判出偏移就不显示。
  **默认关**的原因见第五节的实测：B站 AI 字幕几乎句句相连、中间不留停顿，这种字幕上根本判不出偏移（会误报「对齐」，已改成明确写「判不出」）。所以它只在**有人工字幕、句子之间有停顿**的视频上才真的有用。设置里可以开。
- **分 P（v0.5.1）**：多 P 视频换 P 不用刷新页面，字幕和笔记自动换成新那一 P 的。状态条最前面多一个小标记「P3/70」，鼠标悬停看这一 P 的名字；导出时文件名和 frontmatter 都带上 P 号。每个分 P 的笔记分开存（IndexedDB 键里带 cid），切回来时原样恢复。
- **队列进度与失败处理（v0.5.3）**：状态条会写「整理 4:21–4:50 · 还有 12 段 …」，队列跑空时变回字幕来源。
  遇到限流（429）/网络抖动/超时会自己退避重试三次（限流等 5s、10s），期间状态条写「排队中 · 等 5s（还有 12 段）」——
  不会卡在某一口上假装在干活，也不会把这一段悄悄吞掉。真的失败了（Key 无效、额度用光等）队列会**停下来**，
  面板底部出现「继续整理」按钮，点它接着跑；不点它就不会在后台反复发请求。
- 状态区：字幕来源与可信度、当前在处理哪一段、已花 token 与估算费用。
- 第二行是功能键：**大纲 ▾ / 导出 / 设置 / 收起 ▸**。
  - 「大纲」展开或收起全片的一句话索引，可点跳转，跟着播放头高亮当前那一条。
  - 「导出」导出 Markdown（带 frontmatter、带时间戳、带可点链接），可直接进 Obsidian。
    画面文字也会一起导出：每条笔记下面多一段「画面文字（OCR，机器识别，可能有错字，不是原话）」，每张画面单独给时间与跳转链接，OCR 原文放在代码块里以保留换行。frontmatter 里多一行 `visual_frames: N`（没有画面文字就不写）。多 P 视频的时间链接是 `?p=2&t=22` 这种形式，点开直接落到那一 P 的那一秒。
  - 「设置」填 API Base / 模型 / Key。
  - 「收起 ▸」把面板收成右边缘一条 44px 竖条，竖条上写着「笔记 ◂」，点它展开。
- 左侧边缘可拖动改宽度（280~720px，会记住）。

## 四、字幕不可信这件事，是怎么处理的

B站的 AI 字幕接口**同一个视频多次请求会返回不同文件**（实测：194 秒的视频能返回 1606 秒的字幕；两个不同街舞视频返回同一首歌的歌词）。所以字幕进入笔记前要过闸门：

| 闸门 | 判据 | 失败时状态条 |
| --- | --- | --- |
| 存在性 | 有中文轨且有 url | 没有字幕 / 字幕轨为空 |
| 时长 | 覆盖比 = 末句时间 / 视频时长，要求 0.85~1.10 | 字幕不完整 / 字幕时长超出视频 |
| 结构 | ≥8 行、≥120 字、平均句长≥3、累计时长比≤1.15、最大空档≤max(90s, 时长×10%) | 字幕结构异常 |
| 稳定 | 最多取样 5 次，**按哈希投票**：同一份文件拿到 3 票就提前收；跑完取票最多的，票数 ≥2 才算 stable，只有一份通过算 single | 单次取样（未复核） |
| 登录 | 未登录直接停 | 请先登录 B站 |

- 「两次取样一致」只说明**取样稳定**，**不说明内容一定属于这个视频**（已实测到时长对得上但内容是别的视频歌词的情况）。所以界面文案不写「已验证」。
- **v0.6.1 改成投票**：2026-11-13 拿用户自己的课 BV1JynA6aEug 实测，同一个 (aid,cid) 连取 8 次返回 **4 种不同文件**（正确那份出现 5 次，另外 3 份分别是电动车、擦桌子、HTML 错误页）。取「第一个通过」会有一半概率把别的视频的笔记写给你。改成投票后，真机一次通过 `stable`（2 票），首句是「上一期我们把排练打卡工具要做什么」——正确内容。
- 票数打平（两种文件各 2 票）或每次都不一样时**不猜**：判 `ambiguous`，状态条「字幕每次都对不上」，给「再试一次」。宁可让你重试，也不给你一份内容错的笔记。
- 通过一次后，字幕原文写进 IndexedDB（键 `bvid:cid`），下次打开同一个视频直接复用，不再重新赌接口。（这是必须的：同一视频下一页重载可能又拿到垃圾文件。）
- 失败态给「再试一次」按钮，不走页面刷新。
- **字幕是不是人话，闸门以前查不出来**（外语视频的机翻轨和正常转写长得一样，状态条都写「B站 AI 字幕」）。v0.5.4 起多一层「可读性」检查，但它**不拦字幕**，只在界面上如实标注。

## 六、费用

单块 prompt 约 500~600 token，输出约 100~150 token。70 分钟的视频约 120 块 ≈ 6~7 万 input token。按 ¥1/百万 token 的便宜模型算，一个视频几分钱到一毛钱。浮层右上角实时显示。

## 七、已知问题

- 展开时会把 B站 主容器收窄，视频和右栏整体左移，不盖住画面（收起后恢复原宽度）。窗口太窄时（视频左边被挤出屏幕）会自动放弃让位、退回覆盖模式，此时面板会盖住右侧推荐栏（但不盖视频）。
- 分 P 靠「播放器高亮项（`.video-pod__item.active` 的 data-key = cid）」认当前 P，靠 URL 的 `?p=N` 兜一层；**合集（同一 UP 的一串独立视频）不是分 P**，那种页面没有分 P 列表，切换靠「视频时长和当前 P 差 >5% 且能对上另一个 P」自校正，可能认不出来。
- 一个分 P 也没字幕时，整条视频在那一 P 上就是「没有字幕」；不会回退去总结别的 P。
- 直播回放、番剧、课程（cheese）不做。
- 块时长硬上限 45 秒是「到点就切」，单句特别长时会出现 47 秒左右的块。
- 引文是整句拼接（句间用「……」），有时会比较长；界面只显示前 3 行，鼠标悬停看全文，导出 Markdown 里是完整的。
- 投票也只能防「少数派错误」：如果某次接口连着 3 次返回同一份错文件，投票会把它当真（这种情况目前没样本，但原理上防不住）。
- 字幕接口有时整个视频都拿不到像样的文件（5 次全废），状态条写「字幕取样不稳定」。这时可以点「再试一次」重新取样，或者用「用画面字幕试试」（如果字幕是烧在画面里的）。这是 B站 接口的抖动，不是扩展能修的。
- 「看过 80%」的计时只在连续播放时累计（相邻两次 timeupdate 间隔 >3 秒视为跳转，不计）。所以 2~4 倍速看算看过，但「拖一下再拖一下」的碎片式浏览可能补不满 80%，那块会一直留在虚线里。
- 小节标题每 8 段才出一次，最后不满 8 段的那一截没有小节标题；小节标题也要多花一次模型调用（约 150 token 输入）。
- 占位条上的「正在看 / 未观看」是渲染那一刻的快照：播放头刚进到一个新的虚线区间时，文字要等下一次渲染（块看完、或你动了一下）才会更新。
- 冷启动恢复的是笔记，不是「看过哪些区间」的精确计时——恢复后的那些块靠笔记本身算已覆盖；其余区间的 80% 计时从这次打开重新开始。
- 走神只认三个信号（切走/最小化 >90 秒、手动暂停 >2 分钟、锁屏休眠表现为同一种 hidden）。鼠标静止、画面没变化、倍速播放都不算走神。
- 走神区间不落盘：关掉页面再打开，之前的离开记录就没了（笔记上的「你当时不在页面上」标记会跟着笔记一起存下来）。
- 画面文字只认「连续稳住约 2.4 秒」的帧，所以游戏、影视、镜头一直在动的课程实录可能一张都截不到；这不是坏了，是设计（截了也是糊的/没信息的）。
- 画面文字是 OCR 出来的，会有错字（尤其公式、手写板书、艺术字）；它只进「人话解释」，不进引文，看到可疑的地方以字幕和原视频为准。
- 画面文字挂在**时间最近的块**上（一块最多 2 张帧、每张最多 600 字），不是逐帧存。导出 Markdown 会带上画面文字（v0.5.2），但它不进问答上下文。
- 队列是**串行**的（一次只总结一块）：这是故意的——每一块都要承接上一块的「如果只记一件事」来保持连贯，并发会打断这条链。所以 120 块的视频依赖「边看边跑」，一次性补齐会比较慢。
- 退避重试只覆盖限流/网络/超时/5xx；Key 无效这类错误重试没有意义，直接停下等你处理。
- 音画对齐默认关，而且对 B站 AI 字幕判不出来（覆盖率 >90% 直接放弃）。它只在「句子之间确实有停顿」的字幕上才有意义；开着它还会短暂接管音频输出，极少数情况下可能影响播放声音。
- 时间校正只作用于界面显示和跳转，不改变已存笔记里的时间；如果中途才判出偏移，之前渲染的条目要等下一次重绘才按新偏移显示。
- 机翻检测是启发式，**宁可漏报**：它只认「被+音译名+动词」这类硬结构，正常中文里夹英文术语不会触发；真实外语机翻视频（整段）还没有端到端样本，目前只有用户截图那六句 + 正常中文的回归。
- 画面字幕只认画面下方那条字幕带（画面高度 58%~98.5%）：字幕贴在画面中部、竖屏视频、字幕带被台标挤乱时可能认不到或认错。
- 画面字幕的错字会进原话（它读的就是像素）：数字、人名、公式最容易错，看到可疑的地方以原视频为准。它不进「画面文字」通道，两者互不影响。
- 画面字幕要一直保持播放（每 0.6 秒采一次、每帧 OCR 约 1 秒）；不播就停在那儿，不会自己去读没看过的部分。
- 画面字幕的分辨率闸是 700 像素高（约 720p）：480p/360p 直接拒绝。B站 未登录最高 480p，所以这条路实际上也要求登录。
- 轻量包（`-lite.zip`）没有本地 OCR：画面文字、画面字幕兜底两个功能整体不存在（按钮直接隐藏）。要用这两个功能就换完整包，别去点——按钮不在就没法点。
- 工具栏图标要先钉出来：Edge 默认把新扩展收在拼图（`⋮⋮`）菜单里，点拼图 → 把「B站可核对笔记」钉到工具栏。没钉也能用（拼图菜单里点它一样生效），只是多点一步。
- **装扩展之前就开着的视频页**没有内容脚本：点图标会补注入一次（约 0.4 秒后才生效）。补注入失败时图标上会出现橙色「↻」角标，意思是「这一页要按 F5」。
- 字幕内容校验（抽样 ASR）还没做，见 docs/decisions-bilibili-video-summary.md。
